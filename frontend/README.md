# Horizon VelitIQ — Next.js Web Portal

Enterprise frontend for **Horizon VelitIQ**, built with **Next.js 16 (App Router)**, **TypeScript**, **Tailwind CSS**, and **Lucide Icons**.

See the root [`../README.md`](../README.md) and [`../docs/`](../docs/) for full executive, architectural, and deployment documentation.

## Commands
```powershell
npm install
npm run dev     # Development server on http://localhost:3000
npm run build   # Production TypeScript & bundle verification
npm run start   # Production server
```
